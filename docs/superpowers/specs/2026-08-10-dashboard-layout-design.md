# 个人记账系统第一版界面设计

## 目标

第一版采用轻量的双栏仪表盘，优先保证记账流程清楚、电脑和手机均可使用。同时将界面拆成独立组件，为以后改成带侧边栏的后台布局保留迁移空间。

## 页面结构

- 顶部：应用名称和简短说明，不再显示 Vue 默认 Logo、欢迎内容和 About 导航。
- 汇总区域：三张卡片显示总收入、总支出和当前结余。
- 主体左侧：新增账目表单，保留先选择收入或支出的流程。
- 主体右侧：账目列表，显示日期、类型、分类、备注和金额。
- 窄屏：双栏自动改成单栏，表单位于列表上方。

## 视觉方向

- 使用浅色、简洁的仪表盘风格。
- 收入使用绿色，支出使用红色，其他内容保持中性色。
- 卡片、输入框和按钮使用一致的圆角、间距与边框。
- 第一版不加入复杂动画、深色模式、图标库或最终品牌设计。

## 组件边界

- `SummaryCards.vue`：接收账目数组，计算并显示收入、支出和结余。
- `TransactionForm.vue`：负责表单输入、校验和提交事件，不直接决定页面布局。
- `TransactionList.vue`：接收账目数组并渲染列表。
- `HomeView.vue`：负责读取后端数据、保存账目，并组合三个组件。
- `App.vue`：只提供应用外壳和路由出口。

未来改成侧边栏布局时，保留上述三个业务组件，只增加侧边栏和页面导航并重新排列组件。

## 数据流与错误处理

1. `HomeView.vue` 加载时通过 GET 接口取得账目并传给列表和汇总组件。
2. 表单提交时向父组件发送账目数据，由 `HomeView.vue` 调用 POST 接口。
3. 保存成功后重新读取账目，使列表和汇总同步更新。
4. 读取或保存失败时显示明确提示，保留用户已填写的内容以便重试。

## 验证标准

- 页面加载后显示数据库中的现有账目。
- 新增收入或支出后，列表和三张汇总卡片立即更新。
- 收入、支出和结余金额计算正确。
- 电脑宽度显示双栏，窄屏自动显示单栏且没有横向溢出。
- 前端 lint 和 production build 均通过。
